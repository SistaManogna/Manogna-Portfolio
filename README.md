#  MY PORTFOLIO

 **A little creativity, a little code, and a whole lot of me!**

An interactive, desktop-inspired personal portfolio featuring animated folders, pastel aesthetics, and a personalized avatar.

### 🛠️ Tech Stack
React.js · JavaScript · Vite · CSS · Framer Motion

### 📂 Explore
About Me · Resume · Projects · Interests · Achievements · Hobbies · Contact

### 🚀 Run Locally
```bash
npm install
npm run dev
```
